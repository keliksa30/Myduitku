# MyDuitku 🐾

**Atur aja duitmu.** (Just manage your money)

MyDuitku is a modern, mobile-first personal finance tracker with a unique twist: **Gamification via a Virtual Pet Companion**. Built with Next.js, React, and Tailwind CSS, it transforms the mundane task of budgeting into an engaging and interactive experience.

## 🌟 Features

*   **Cozy Virtual Companion:** Your financial health directly affects your virtual cat's mood. Keep your expenses under budget to keep your cat happy!
*   **Intuitive Expense Tracking:** Easily record your daily expenses with customizable categories and color tags.
*   **Visual Analytics:** Understand your spending habits at a glance with interactive pie charts and breakdown summaries.
*   **Built-in Mini-Game (Mew-Whack):** Feeling stressed about money? Play the integrated whack-a-mole style mini-game to take a break and set high scores.
*   **Privacy First:** 100% offline and local. All your financial data is stored securely on your device's local storage. No servers, no tracking.
*   **PWA Ready:** Install MyDuitku directly to your smartphone's home screen for a native app-like experience.
*   **Immersive UI/UX:** Enjoy smooth micro-animations, haptic feedback (on supported devices), and a dynamic environment that changes based on your interactions.

## 🚀 Tech Stack

*   **Framework:** [Next.js](https://nextjs.org/) (App Router)
*   **Language:** [TypeScript](https://www.typescriptlang.org/)
*   **Styling:** [Tailwind CSS](https://tailwindcss.com/)
*   **State Management:** [Zustand](https://github.com/pmndrs/zustand)
*   **Charts:** [Recharts](https://recharts.org/)
*   **Deployment:** Vercel (Recommended) / Static Export

## 📦 Getting Started

First, clone the repository and install the dependencies:

```bash
git clone https://github.com/keliksa30/Myduitku.git
cd Myduitku
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 🎨 Design Philosophy

MyDuitku was designed to move away from intimidating, spreadsheet-like financial apps. By incorporating soft colors, playful typography (Plus Jakarta Sans & Quicksand), and an interactive environment, it encourages users to build healthy financial habits without the anxiety.
